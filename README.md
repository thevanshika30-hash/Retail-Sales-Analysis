# Retail Sales Analysis Using Python
## 📌 Project Overview

This project analysis retail sales data using Python. The project focuses on understanding sales and profit patterns across different products, categories, locations, and months.

Data analysis, visualisation, correlation analysis, and Machine Learning are used to generate useful business insights and predict sales.

## 🎯 Objectives

- Analyse retail sales data.
- Identify the best-selling products.
- Compare sales across different categories.
- Compare sales across different locations.
- Analyse monthly sales trends.
- Analyse profit by category.
- Study relationships between numerical variables using correlation.
- Build a Machine Learning model for sales prediction.
- Evaluate the performance of the prediction model.
- Generate useful business insights.

## 🗂️ Dataset

The dataset contains 400 retail sales records.

Important columns include:

- Order ID
- Product
- Category
- Quantity
- Discount
- Unit Price
- Sales
- Profit
- Location
- Order Date

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## 🔍 Project Methodology

### 1. Data Creation

A retail sales dataset containing 400 records was created for the analysis.

### 2. Data Cleaning

The dataset was checked for:

- Missing values
- Duplicate records
- Data types
- Basic data quality

### 3. Exploratory Data Analysis

The data was analyzed using:

- `groupby()`
- `sum()`
- `describe()`
- Statistical analysis
- Product-wise analysis
- Category-wise analysis
- Location-wise analysis

### 4. Data Visualisation

The following visualisations were created:

- Sales by Product
- Sales by Category
- Sales by Location
- Monthly Sales Trend
- Profit by Category
- Correlation Heatmap
- Actual vs Predicted Sales

### 5. Correlation Analysis

Correlation analysis was used to study relationships between numerical variables such as:

- Quantity
- Discount
- Unit Price
- Sales
- Profit

### 6. Machine Learning

A Linear Regression model was developed to predict sales.

The model used features such as:

- Quantity
- Discount
- Unit Price
- Month

### 7. Model Evaluation

The model was evaluated using:

- MAE
- RMSE
- R² Score

## 📊 Results

The analysis produced the following results:

| Analysis | Result |
|---|---|
| Highest Selling Product | Laptop |
| Highest Selling Category | Clothing |
| Highest Selling Location | Jaipur |
| Highest Profit Category | Clothing |
| Highest Sales Month | January |
| Lowest Sales Month | December |
| MAE | 17,057.26 |
| RMSE | 23,047.35 |
| R² Score | 0.7917 |

## 💡 Business Insights

- Laptop was the highest-selling product in the analysed dataset.
- Clothing recorded the highest total sales among the product categories.
- Jaipur recorded the highest total sales among the analysed locations.
- Clothing generated the highest total profit.
- January recorded the highest total sales.
- December recorded the lowest total sales.
- The Linear Regression model achieved an R² score of approximately 0.792 on the test data.

This project demonstrates how Python can be used to analyse retail sales data and extract meaningful business insights.
